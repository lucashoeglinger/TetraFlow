# Tetraflow

This is a Tetris based project developed primarily in **Javascript** and **Apache Cordova**. This project was developed as a Project for the `Coding Academy` of the *Wifi Oberösterreich*.


## Folder Structure

TetraFlow/
├── public/
│   ├── favicon.ico
│   ├── index.html
│   └── ...
└── source/
    ├── backend/
    ├── components/
    ├── contexts/
    ├── hooks/
    ├── sound/
    ├── utils/
    ├── App.js
    ├── index.js
    └── ...


## Features

- gyroscope api
- Leaderboard with supabase
- Level updates with original logic
